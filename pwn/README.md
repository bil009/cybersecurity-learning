# Pwn

Exploration of low-level security and binary exploitation.

## Intended learning path
- Linux process fundamentals
- Binary formats and ELF
- Memory layout
- Registers
- Assembly fundamentals
- Stack behavior
- Calling conventions
- Debugging
- Buffer overflows
- Binary exploitation fundamentals

## Current status
This section is being developed. Topics will be documented only after practical exploration and verification.

## Lab record template
For each challenge, document:
- Challenge and environment
- Program behavior
- Relevant binary observations
- Debugging process
- Vulnerability analysis
- Exploitation reasoning
- Evidence
- Lessons learned
