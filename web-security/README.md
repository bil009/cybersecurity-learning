# Web Application Security

My primary cybersecurity learning direction.

Focus: understanding how web applications process input, manage authentication and authorization, interact with databases, and expose security vulnerabilities.

## Topics
- SQL Injection (SQLi)
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Broken Access Control
- Command Injection
- HTTP, sessions and cookies

Practice environments:
- PortSwigger Web Security Academy
- SQLi-Labs
- pwn.college

Learning approach: analyze the application, understand the request and execution context, test in authorized environments, verify impact and study remediation.
