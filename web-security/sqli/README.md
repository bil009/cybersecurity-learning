# SQL Injection (SQLi)

SQL Injection occurs when user-controlled input influences the structure of an SQL query in an unintended way.

My learning focuses on understanding query construction, injection contexts, database behavior, manual testing and defensive approaches.

## Concepts Studied

- SQL query structure
- Injection contexts
- UNION-based SQL injection
- Column count identification
- Database enumeration
- Error-based SQL injection
- Blind SQL injection
- Cookie-based injection
- Filter and blacklist bypasses
- Automated testing with SQLmap
- Manual testing and request analysis

## Practice

- SQLi-Labs
- PortSwigger Web Security Academy
- Pwn.college

## Approach

Rather than memorizing payloads, I focus on:

1. Identifying where input enters the query.
2. Understanding the original SQL statement.
3. Analyzing the injection context.
4. Testing how the database interprets input.
5. Verifying the result.
6. Understanding how to prevent the vulnerability.
